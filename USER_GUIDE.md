# Инструкция для пользователя

## Назначение бота
Бот нужен для учета вашей работы и связанных с ней расходов.

Через бота можно:
- зарегистрироваться в системе;
- привязать второй мессенджер;
- вносить смены и монтажи;
- отправлять расходы на подтверждение;
- смотреть свои записи;
- смотреть свои расходы;
- смотреть статистику за первую или вторую половину текущего месяца;
- получать уведомления о решениях администратора, премиях и штрафах.

Бот работает в Telegram и VK. Основная логика в обоих каналах одинаковая, но интерфейс немного отличается:
- в Telegram основная навигация идет через inline-кнопки и меню;
- в VK используются кнопки клавиатуры и команды.

## Доступ после регистрации
После первой регистрации создается заявка на доступ. Пока администратор ее не подтвердит:
- вносить рабочие данные нельзя;
- смотреть рабочую статистику нельзя.

После подтверждения бот отправит вам уведомление.

## Ваш ID
У каждого сотрудника есть внутренний ID в системе.

Он нужен для:
- поиска вашей записи администратором;
- привязки второго мессенджера;
- объединения дублей аккаунтов при необходимости.

Команда в Telegram:
```text
/my_id
```

Команда в VK:
```text
/my_id
```

## Привязка VK к Telegram-аккаунту
Если вы уже зарегистрированы в Telegram и хотите пользоваться ботом в VK, нужно привязать VK к существующей записи.

Как это сделать:
1. В Telegram выполните:
```text
/link_vk
```
2. Бот выдаст одноразовый код привязки.
3. Откройте бота в VK.
4. Нажмите `/start`.
5. Выберите вариант, что аккаунт уже есть.
6. Отправьте код из Telegram.

После этого VK будет привязан к вашей существующей записи, и новый сотрудник создан не будет.

## Доступные команды

### Telegram
```text
/start
/help
/my_id
/link_vk
/my_logs
/my_expenses
```

### VK
```text
/start
/help
/my_id
/add
/stats
/my_logs
/my_expenses
/cancel
```

## Главное меню
Большинство действий удобнее делать кнопками, а не командами.

В главном меню доступны:
- `Внести информацию`
- `Посмотреть статистику`
- `Мои записи`
- `Мои расходы`
- `Помощь`

## Внесение рабочей записи
Через бота можно внести три типа данных:
- монтаж;
- смену;
- расход.

Общий сценарий:
1. Откройте главное меню.
2. Выберите `Внести информацию`.
3. Укажите число месяца, к которому относится запись.
4. Выберите тип записи:
   `Монтаж`, `Смена` или `Расходы`.
5. Заполните нужные поля.
6. Подтвердите сохранение.

### Монтаж
Для монтажа бот попросит:
- дату;
- название проекта, объекта или комментарий;
- количество часов.

### Смена
Для смены бот попросит:
- дату;
- количество часов.

### Расход
Расходы — это личные деньги сотрудника, потраченные на нужды компании, которые потом компенсируются.

Примеры:
- покупка материалов;
- покупка инструмента;
- дорога на объект за свой счет;
- срочная докупка расходников.

Для расхода нужно указать:
- дату;
- описание;
- сумму;
- чек, если он есть.

### Чек
Чек прикладывать можно, но не обязательно.

Если чек есть:
- в Telegram можно отправить фото или документ;
- в VK можно отправить фото или файл.

Если чека нет:
- выберите `Продолжить без чека`.

### Что происходит после отправки расхода
1. Расход сохраняется в системе.
2. Он получает статус `pending`.
3. Администратору уходит заявка на подтверждение.
4. После решения администратора вы получаете уведомление.

### Куда приходит ответ по расходу
Уведомление о результате приходит туда же, где расход был создан:
- если расход заведён в Telegram, ответ придет в Telegram;
- если расход заведён в VK, ответ придет в VK.

## Просмотр своих данных

### Рабочие записи
Команда:
```text
/my_logs
```

Показываются записи текущего месяца:
- дата;
- тип записи;
- часы;
- проект, если он указан.

### Расходы
Команда:
```text
/my_expenses
```

Показываются расходы текущего месяца:
- дата;
- сумма;
- описание;
- статус;
- отметка о чеке, если чек сохранен.

Статусы расходов:
- `pending` — ожидает подтверждения;
- `approved` — подтвержден;
- `rejected` — отклонен.

## Статистика
Статистика показывается за:
- первую половину месяца;
- вторую половину месяца.

В статистике отображается:
- количество смен;
- часы по сменам;
- количество монтажей;
- часы по монтажам;
- премии;
- штрафы;
- подтвержденные расходы;
- начислено по ставкам;
- итог к выплате.

## Уведомления
Бот может присылать:
- подтверждение регистрации;
- отклонение регистрации;
- подтверждение расхода;
- отклонение расхода;
- уведомление о начисленной премии;
- уведомление о назначенном штрафе.

## Если что-то пошло не так
Если бот не дает внести данные или пишет, что доступ еще не выдан:
- проверьте, подтверждена ли ваша регистрация администратором;
- убедитесь, что используете тот Telegram или VK-аккаунт, который привязан к вашей записи;
- если аккаунт был создан дважды, попросите администратора объединить дубли.
